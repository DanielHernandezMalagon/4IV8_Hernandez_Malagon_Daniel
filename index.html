Objetivo del Portafolio

Recopilar, estructurar y presentar de forma organizada las prácticas y soluciones algorítmicas desarrolladas a lo largo del curso. Este espacio funge como evidencia del dominio adquirido en la construcción de interfaces estructuradas, estilos dinámicos, lógica de programación en el lado del cliente (JavaScript) y desarrollo en el entorno del servidor con tecnologías como Node.js y Express.

Elementos Aprendidos en la Materia

  • Estructuración y Semántica: Maquetación profesional de documentos web interactivos utilizando HTML5 y CSS3 avanzados.
  • Lógica Dinámica: Manipulación del DOM, validación estricta de formularios y resolución de problemas lógicos mediante JavaScript vanilla.
  • Arquitectura y Servidores: Fundamentos de la arquitectura Cliente-Servidor empleando Node.js, Express y la estructuración de proyectos bajo el patrón de diseño MVC.
  • Control de Versiones: Despliegue seguro de aplicaciones y gestión de entornos colaborativos utilizando repositorios Git y GitHub.
